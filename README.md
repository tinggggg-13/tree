# 存心樹洞 🌳

> 用 AI 把心情種成好心——佛光大學「三好 AI 創新應用競賽」參賽作品

**團隊：** 獨木成林（個人參賽）

## 作品簡介

存心樹洞是一個互動式網頁，把「三好」（做好事、說好話、存好心）與「四給」（給人信心、給人歡喜、給人希望、給人方便）變成每天做得到的小行動：

1. **寫下心情**：選一個心情標籤、寫幾句話，放進樹洞。
2. **AI 溫暖回應**：AI 先具體回應你的感受（說好話），再派一個 5 分鐘內做得到的「四給任務」。
3. **完成打卡、種出好心樹**：每完成一個任務，樹就長出一片葉子；每 5 片開一朵花，從種子一路長成菩提樹（存好心）。
4. **匿名好話信箱**：完成任務後，可以寫一句好話寄給一位陌生的樹洞夥伴（做好事）。

## 安全設計

- **不會變成交友管道**：信件匿名、單向，不能回覆、私訊或加好友，只保存雜湊過的代號。
- **三道防線防止不雅言語**：
  1. 本機規則：擋下髒話、聯絡方式（LINE、IG、電話、網址）和邀約。
  2. AI 善意檢查：擋下嘲諷、否定感受等隱晦的話，並提供溫柔的改寫建議。
  3. 收信端：開信前再過濾一次，收到不舒服的信可以一鍵檢舉、隱藏。
- **危機偵測**：偵測到自我傷害相關內容時，會提供 1925 安心專線、1995 生命線、1980 張老師等求助資訊。

## 檔案結構

```
index.html   頁面結構
style.css    樣式
script.js    互動邏輯、AI 串接、好話信箱、好心樹繪製
```

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository，例如 `cunxin-treehole`。
2. 把 `index.html`、`style.css`、`script.js`、`README.md` 上傳到 repository 根目錄。
3. 進入 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一到兩分鐘，網站就會出現在 `https://你的帳號.github.io/cunxin-treehole/`。

## 關於 AI 與好話信箱

| 功能 | 在 claude.ai 上 | 在 GitHub Pages 上 |
|---|---|---|
| AI 回應與任務 | ✅ 即時生成 | 離線示範（內建範本） |
| AI 善意檢查 | ✅ | 只用本機規則檢查 |
| 好話信箱（寄給陌生人） | ✅ 真的送到別人手上 | 離線示範（內建範例信） |
| 心情紀錄、好心樹 | ✅ 雲端保存 | ✅ 存在瀏覽器裡 |

GitHub Pages 只能放靜態網頁，沒有後端。要讓 AI 在 GitHub 版本上也能運作，需要另外架一個後端（例如 Cloudflare Workers 或 Vercel Functions），讓它代為呼叫 AI API，然後把網址填進 `script.js` 開頭的 `CONFIG.AI_ENDPOINT`。

> ⚠️ 不要把 AI 的 API 金鑰直接寫在 `script.js` 裡。放在 GitHub 上的檔案所有人都看得到，金鑰會被盜用。

要讓好話信箱在 GitHub 版本上真的寄給別人，也需要一個共用資料庫（例如 Firebase Firestore）。
